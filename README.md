# Nacht der Bestien

Ein browserbasiertes Action-Spiel mit 50 Leveln, drei spielbaren Charakteren, steigender Schwierigkeit, Bosskampf auf Level 50 und Speicherpunkten alle 5 Level.

## Lokal starten

Einfach `index.html` im Browser öffnen.

## GitHub Pages Deployment

Bei jedem Push auf den `main`-Branch wird das Spiel per GitHub Action automatisch auf GitHub Pages veröffentlicht.

Workflow-Datei: `.github/workflows/deploy-pages.yml`
