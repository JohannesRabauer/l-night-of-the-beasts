# Nacht der Bestien

Isometrisches Action-RPG im Browser (Victor-Vran-Stil): Echtzeitkampf, Ausweichen, Overdrive, 50 Level.

## Die 50 Level

| Level | Gebiet | Schwierigkeit |
|------:|--------|---------------|
| 1–10 | Die alte Stadt | ★ |
| 11–20 | Der schwarze Wald | ★★ |
| 21–30 | Das verlassene Schloss | ★★★ |
| 31–40 | Die Nebellande | ★★★★ |
| 41–49 | Die Unterwelt | ★★★★★ |
| 50 | Das letzte Reich | ☠️ |

## Charaktere

- **Jugendlicher** — schnell, Schall-Fernkampf, Kopfhörer orten Feinde (besonders im Nebel).
- **Puma mit Helm** — Sprung, Klettern über Trümmer, Helm-Designs, später Dämonenrüstung.
- **Werwolf** — startet schwach, wird pro Gebiet stärker; Lebenskraft-Raub erst ab den Nebellanden.

## Steuerung

- **WASD / Pfeile** bewegen
- **Linksklick** angreifen
- **Shift / Rechtsklick** ausweichen
- **Q** Charakterfähigkeit
- **F** Overdrive (volle Leiste)
- **Leertaste** Sprung (Puma)
- **Esc** Pause

Stirbst du, wachst du am letzten Speicherpunkt auf (alle 5 Level), nicht am Spielanfang.

## Lokal starten

`index.html` im Browser öffnen.
